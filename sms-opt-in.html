RainMaker SMS opt-in

Santa Cruz Studios operates RainMaker Morning, a private trading workspace. SMS alerts are owner-only and collected inside the authenticated app. This page documents the exact consent language shown to the user (static replica for verification).

Alerts & automations (in-app)

After sign-in: Account → Alerts & automations

Morning text and General text toggles stay disabled until the consent box above is checked.

How opt-in works

  1. User signs in to RainMaker Morning (Google OAuth).
  2. User opens Account → Alerts & automations.
  3. User enters their mobile number (E.164).
  4. User checks the unchecked SMS consent box (language above).
  5. User taps Save alert settings.
  6. User may optionally enable Morning text / General text after consent.

Sample messages

Rainmaker morning | Market: Bullish (+0.4%) | Picks: BOC, IMCC. Reply STOP to opt out.
Rainmaker: Research ready - BOC catalyst summary. Reply HELP for help. Reply STOP to opt out.

Opt-out & help

  • Reply STOP to cancel SMS at any time.
  • Reply HELP for support information.
  • Message frequency: about 1–5 texts per trading week.
  • No purchased lists; no third-party marketing.
